Classes

A rundown of coursework at Texas A&M and before, most recent first — official course descriptions, why each one actually mattered, and a few personal notes from along the way.

Fall 2026

ECEN 403

Electrical Design Laboratory I

The start of the senior design sequence — team-based project engineering as practiced in industry, from project proposal through execution and validation planning.

Impact:Kicks off my senior design project — the first time the degree turns into a real, sponsor-backed engineering project instead of a class assignment.

ECEN 475

Introduction to VLSI Systems Design

Design and fabrication of microelectronic circuits, with an emphasis on very-large-scale integration (VLSI) digital systems using modern design tools.

Impact:Closes the loop from ECEN 248's basic logic gates all the way to an actual fabricated chip.

CSCE 410

Operating Systems

How operating systems evolved alongside computer architecture — CPU scheduling, memory and resource allocation, and process coordination and management.

Impact:Ties architecture, systems programming, and algorithms together into the one piece of software every other program runs on top of.

CSCE 463

Networks and Distributed Processing

Computer network design and protocol analysis through a layered-architecture lens, mixing network engineering theory with hands-on protocol programming.

Impact:Directly applicable to almost any distributed or web-connected system I'll ever build.

CSCE 481 · 1 credit

Seminar

A seminar exposing students to current topics in computer science with a focus on leader development — job seeking, the workplace, and graduate school, via invited speakers.

Impact:A low-key but useful gut-check on career planning and what industry versus grad school actually look like.

ANTH 210

Social and Cultural Anthropology

A core anthropology course examining human cultures and societies — kinship, belief systems, economics, and social organization — through a cross-cultural, comparative lens.

Impact:A required look outside engineering — a reminder that the systems I build are used by people shaped by very different cultures and assumptions.

Summer 2026

Study Abroad — France

CSCE 411

Design and Analysis of Algorithms

Algorithm design paradigms, time/space efficiency analysis, correctness proofs, and an introduction to NP-completeness and undecidability.

Impact:Big-O analysis is the difference between code that works and code that scales — a core skill for any technical interview or production system.

Spring 2026

ECEN 454

Digital Integrated Circuit Design

Analysis and design of digital integrated circuits using MOS and bipolar technology, with computer-aided simulation.

Impact:Seeing how a chip is actually laid out and simulated demystified the hardware inside every device I use.

ECEN 449

Microprocessor System Design

Hands-on FPGA-based design — building microprocessor systems in Verilog, memory-mapped I/O, interrupts, and hardware/software co-design.

Impact:Building a working microprocessor system on an FPGA connected years of digital logic theory into one tangible, working system.

ECEN 325

Electronics

Analog circuit design — op-amps, diodes, BJTs, and MOSFETs — plus linear and non-linear circuit analysis using Laplace transforms and Bode plots.

Impact:Analog is where theory meets the messiness of real components — this built the intuition for reading and debugging real circuits.

CSCE 331

Foundations of Software Engineering

A writing-intensive, team-based course focused on building a larger piece of software together, emphasizing integration, documentation, and process.

Impact:My team designed and built a full website together end-to-end, and this is where I learned how much one person's code affects everyone else's on a shared codebase. It's also where Git and GitHub went from a checkbox skill to something I now use daily for version control and real collaboration.

Fall 2025

13 credit hours
STAT 211

Principles of Statistics I

Data summaries, probability distributions, sampling distributions, hypothesis testing, and regression.

Impact:Statistics literacy that's paid off in every lab report and dataset since — knowing when a result is actually significant.

MATH 311

Topics in Applied Mathematics I

Linear algebra — matrices, vector spaces, eigenvalues — paired with vector calculus: gradient, divergence, curl, and the integral theorems.

Impact:The linear algebra here is the backbone behind everything from computer graphics to machine learning.

ECEN 314

Signals and Systems

Analysis of continuous and discrete-time signals and systems — Fourier series/transforms, Laplace and Z-transforms, convolution, and system stability.

Impact:This is the math behind every sensor, filter, and communication system in ECE — the class that made it concrete instead of abstract.

CSCE 313 (Honors)

Introduction to Computer Systems

Systems-level programming — the OS/application interface, inter-process communication, introductory network programming, and basic computer security — with hands-on labs.

Impact:First class where the OS stopped being invisible — writing code that talks directly to processes and the network.

Summer 2025

Study Abroad — Japan 7 credit hours

Read more about this study abroad experience on LinkedIn.

ECEN 469

Advanced Computer Architecture

Builds on core architecture with advanced memory system design, pipelining techniques, out-of-order execution, and multiprocessor/parallel structures.

Impact:Learning advanced architecture alongside engineers from another country gave a broader, less US-centric view of how the industry builds hardware.

ECEN 350

Computer Architecture and Design

How computers are built from the instruction set up — datapath and control design, pipelining, and memory hierarchy — using register-transfer languages and simulation tools.

Impact:Demystified what a CPU actually does between fetching an instruction and executing it — the biggest lightbulb moment of the degree so far.

Spring 2025

14 credit hours
MATH 308

Differential Equations

Ordinary differential equations, series solutions, Laplace transforms, and systems of differential equations.

Impact:Differential equations show up constantly in signals, systems, and controls — this is what made those later classes tractable.

ECEN 214

Electrical Circuit Theory

Fundamentals of circuit analysis — Ohm's and Kirchhoff's laws, resistive/capacitive/inductive circuits, and Thevenin/Norton equivalents.

Impact:Circuit fundamentals that underpin every hardware class that followed, from digital design to VLSI.

CSCE 222

Discrete Structures for Computing

Mathematical foundations for computing — logic, proofs, and set theory — plus models of computation like finite state machines and Turing machines.

Impact:Gave me the proof-and-logic toolkit that makes reasoning about whether an algorithm is actually correct possible.

CSCE 221

Data Structures & Algorithms

Core data structures — stacks, queues, lists, trees, graphs, and hash tables — along with sorting, searching, and analyzing algorithm performance.

Impact:The data structures learned here show up in essentially every technical interview and every serious codebase since.

Freshman Year — Texas A&M

ECEN 248

Introduction to Digital Systems Design

Foundational digital logic course — combinational and sequential circuit design, Boolean algebra, and Verilog.

Taught basic gates and Boolean logic, expanding into the more physical side of technology — exciting as a Computer Engineering major.

Impact:The first time hardware stopped being a black box — understanding gates made everything built on top of them make sense.

CSCE 120

Program Design and Concepts

Introduces program design and computational thinking using C++, including basic and aggregate data types.

Taught me the basics of C++, which felt similar to Java.

Impact:Built the C++ foundation that essentially every later systems and algorithms course at A&M assumes you already have.

ENGR 102

Engineering Lab I: Computation

The required first-year engineering computation course at Texas A&M — Python for engineering problem solving, covering numerical methods, data analysis, and simulation.

My first college coding class, and my first time using Python. A project I remember fondly: parsing 50 years of weather data from a CSV file to find averages, maxes, and mins.

Impact:First real taste of using code to solve an engineering problem instead of just an assignment — turning raw data into an actual answer.

High School

SENIOR YEAR

AP Computer Science A

A college-level AP course in object-oriented programming with Java, covering classes, arrays, and algorithms, and ending in the AP exam.

My favorite class of high school. Coincided with Robotics; for the final project, my partner and I built a Snake game from scratch in Java.

Impact:Proved I could hold my own in a full object-oriented language and helped me decide to pursue Computer Engineering in college.

JUNIOR YEAR

Computer Science B

A non-AP course typically used as a stepping stone toward AP Computer Science A, focused on JavaScript fundamentals.

Taken fully online because of COVID-19. Taught the basics of JavaScript, which prepared me for AP Computer Science A.

Impact:Built the JavaScript fluency that made the jump into AP Computer Science A much smoother.

SOPHOMORE YEAR

AP Computer Science Principles

An introductory, language-agnostic AP course covering the big ideas of computing — algorithms, data, the internet, and computing's impact — built around creating projects rather than mastering one language.

This was my first ever coding class. It used Scratch, a block-coding website, to make projects.

Impact:Opened the door to computer science as a career path and showed that programming could be creative, not just technical.
